001 and 002 landed together in commit `49cf74f`. 003 required a mid-implementation fix — see its Postmortem section: the planned `display: none ↔ block` + `@starting-style` approach didn't animate the open direction in real-browser testing (Chrome 152), so the discrete property was swapped to `visibility` instead. 004 was written to avoid that exact bug class by never toggling `display`/`visibility` (height animated via `grid-template-rows` directly on `<details>`) — but real-browser testing found a *different*, `<details>`-specific bug: it cannot smoothly transition `grid-template-rows` on itself at all, regardless of what triggers the change (native `[open]`, a same-tick class, or even a class deferred by one animation frame). See 004's Postmortem for the full isolation process. The fix that stuck was the native `::details-content` pseudo-element (Chrome 131+), which sidesteps the whole problem — no JS, no wrapper `<div>`, no `display`/`visibility` toggling. 005 was a genuine new-DOM-mount entrance (not a `display`/`visibility` toggle, and not `<details>`-based), so neither prior bug class applied — but real-browser verification still caught a different, smaller bug: Tailwind v4's `translate-y-*`/`scale-*` utilities compile to the standalone CSS `translate`/`scale` properties, not `transform`, so listing `transform` in `transition-property` transitioned a property that never actually changed. Fixed by listing `translate,scale` instead. See 005's Postmortem.

## Recommended execution order

**004 and 005 are both independent of 001/002/003 and of each other** and can run in any order. 004 is CSS-only, touching `.inc-faq`-scoped selectors in `globals.css`. 005 touches a single Tailwind `className` string in `ContactModal.tsx` and adds no CSS to `globals.css` at all — a different file, different styling system (inline Tailwind vs. hand-written CSS), sharing nothing with any other plan in this series.

## Dependencies

None. 004 touches `src/app/globals.css` only inside `.inc-faq details`/`.inc-faq details::details-content`/`.inc-faq summary`/`.inc-faq details p` and adds two rules to the existing `@media (prefers-reduced-motion: reduce)` block — disjoint from where 001/002/003 made their edits. 003 touches `src/app/globals.css` only inside the existing `@media (max-width: 900px)` block and the same reduced-motion block — disjoint from where 001/002 made their edits. 005 touches only `src/components/ContactModal.tsx:443`, a file untouched by every other plan in this series.
