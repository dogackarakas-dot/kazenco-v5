# Development Rule

Avoid modifying stable files whenever possible.

Prefer adding new functionality as:

-   New components
-   New CSS
-   New assets

Example:

``` text
src/components/KazencoProjectPortfolio.tsx
```

This minimizes the risk of breaking stable sections such as Hero,
Products and Footer.
